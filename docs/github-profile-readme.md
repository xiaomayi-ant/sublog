## Maintenance model

The `Recent posts` block should be generated by GitHub Actions from the Markdown content in the Water repository. The workflow should update only the marked block, preserving the rest of the README as authored text.

Recommended flow:

```text
push article to Water
        ↓
Astro tests and build
        ↓
extract latest published posts
        ↓
replace the marked README block
        ↓
commit to sumoer/sumoer
```

Do not make the GitHub profile the canonical content source. Water remains the source of truth; the profile is a concise, automatically refreshed index.
